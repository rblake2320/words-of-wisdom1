# AI Upsell Strategy — Words of Wisdom

Words of Wisdom should use AI as a premium layer on top of the proven creator-content archive. The base value is the daily quote, source-backed archive, and routing back to James Dumoulin's larger ecosystem. AI should increase value by making the archive conversational, personalized, and easier to monetize.

## Core Principle

```text
Base product = daily wisdom + source links + Skool/YouTube routing
AI upsell = ask, explain, personalize, organize, and convert
```

## Premium Consumer Features

| Feature | Description | Tier |
|---|---|---|
| Ask the Wisdom Vault | Ask questions grounded in the approved quote database and source videos | Pro |
| Explain This Quote | Get context, key lesson, action step, and source video link | Plus |
| Personalized Daily Wisdom | Daily quote selection based on goals like discipline, confidence, business, faith, or wealth | Plus |
| Speaker Insights | Ask what a specific guest/speaker has said across the archive | Pro |
| Guided Collections | AI-generated collections such as Comeback Season, Build Discipline, Think Bigger, or Identity Shift | Plus/Pro |
| Weekly Reflection | AI summarizes saved quotes and turns them into reflection prompts | Pro |

## Creator / Partner Features

| Feature | Description | Tier |
|---|---|---|
| Content Extraction | Import more videos/Shorts and extract quotes, topics, speakers, and timestamps | Creator Pro |
| CTA Optimizer | Suggests whether each quote should route to Skool, YouTube, newsletter, course, merch, or coaching | Creator Pro |
| Quote Quality Scoring | Scores quotes for shareability, emotional impact, and conversion potential | Creator Pro |
| Archive Topic Map | Builds a topic graph across James, guests, videos, and categories | Creator Pro |
| Sponsor Fit | Suggests sponsor categories aligned to quote topics and user interests | Enterprise |

## Subscription Concept

```text
Free
- Daily quote
- Browse archive
- Source links
- Basic sharing

Plus
- Unlimited favorites
- Explain This Quote
- Personalized Daily Wisdom
- Guided Collections

Pro
- Ask the Wisdom Vault
- Speaker Insights
- Weekly Reflection
- Advanced search across topics/speakers

Creator/Partner
- Content extraction
- CTA optimization
- Analytics insights
- Premium channel packaging
```

## Guardrails

- AI must not invent statements from James or guests.
- AI answers should cite the underlying quote, source video, and timestamp when available.
- Original quote text must remain clearly separate from AI explanation.
- Public AI-generated content should support human approval.
- If this becomes a licensed creator product, voice/likeness use must require explicit authorization.

## Why It Matters

The app already proves the archive is valuable. AI turns that archive into a higher-ticket product:

```text
559 quotes → searchable archive → wisdom vault → AI adviser → paid subscription
```

That gives James and future creators another monetization lane without making more content first.
